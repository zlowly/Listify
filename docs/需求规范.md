## 1. 产品概述

### 1.1 产品定位

浏览器内零安装的歌单排版工坊：导入一份纯文本歌单（`#分类` + 歌名），系统自动排成适合手机分享的版面，使用者少量调整即可导出 PNG。

差异化：零安装本地运行 + 针对歌单的自动排版规则（按视觉字宽自动列宽、动态行数、自动续表），替代在 PS 或表格里手工对齐。

### 1.2 目标用户

个人使用者（为朋友或社群制作分享图）；低频、一次性的制作任务，无多角色协作。当前以自用为标准，之后可能开放给陌生人使用（“纯本地”底线不变）。

### 1.3 核心价值

- **导入即可用，少调**：导入后自动排好，少量调整即可出图。
- **编辑不丢失**：编辑自动保存在本机，重新打开即可继续；项目可导出为文件备份和迁移。
- **出图即成品**：所见即所得，导出结果干净，不含任何编辑辅助。

输出用途是手机分享图，尺寸、间距、边距均以像素为单位。

### 1.4 产品原则

1. 自动规则优先，手工调整是例外。
2. 纯本地：文件不离开浏览器，零安装、零构建、可离线运行。
3. 歌名对齐按视觉宽度（一个中文字 = 两个拉丁字符），不按字符数。
4. 页面编辑辅助只为出图服务，不出现在导出结果中。
5. 歌单编辑仅限于对已有歌单进行方便快捷的小量调整，对于大量的修改删除用户应该选择在外部使用其他编辑工具更妥当

## 3. 功能需求

### 3.1 歌单

- **导入**：能导入本地文本格式的歌单；自动识别常见中文编码（UTF-8 / GBK 系），自动识别分类与歌名。
- **去重**：重复的分类自动合并、重复的歌名自动跳过，无需手工处理，不自动改名或追加序号。
- **导入方式**：支持整份覆盖与增量追加两种，由使用者选择。
- **重导入友好**：再次导入同一份歌单只更新歌名数据，不打乱页面上已排好的版面。
- **编辑**：能修改分类名；能增、改、删歌名；能把歌在分类之间移动。
- **排序**：能按视觉字数对歌名排序（短歌在前），同长度保持原顺序。
- **查找**：能按歌名关键字快速检索并定位到具体某一首歌。
- **导出**：能把当前歌单按原文本格式导出，重新导入后完全还原。
- **模板**：没有歌单时能导出一份符合格式的示例模板。

### 3.2 页面

- **多页**：能增、删、切换页面；项目至少保留一页。
- **页面尺寸**：支持纵向/横向与常用尺寸，也支持自定义；尺寸对所有页面统一生效。
- **边距**：能设置上、右、下、左页面边距，作为排版参考。
- **浏览**：画布能放大看细节、缩小看全页，浏览方式不影响页面数据与导出结果。

### 3.3 分类块与自动排版

- **放置**：分类能作为方块放到页面上；高度随内容自动变化，宽度默认占满页面内容区。
- **自动排序**：歌名按视觉字数（中文/全角 = 2，拉丁/半角 = 1）自动排序后铺排。
- **填充方向**：支持“逐列铺”与“逐行铺”两种。
- **自动列宽**：按各列最长歌名自动计算列宽，无需逐格手工对齐；也支持手动微调列宽。
- **动态行数**：行数可按歌名数量自动计算；内容超出当前表格时自动续建新表格，不必手工分页。
- **对齐**：歌名支持左对齐、居中、右对齐、两端对齐。
- **溢出提示**：内容超出页面、或歌名超出列宽时，有醒目的可视警示。

### 3.4 文字与字体

- **分类块文字**：分类名与歌名各自独立设置字体、字号、粗细、颜色、行距。
- **文字效果**：支持阴影与轮廓。
- **标题开关**：能隐藏分类标题行，隐藏后版面自动收拢，样式保留可随时恢复。
- **自由文字**：能添加自由文字，样式能力与分类名/歌名一致；能直接编辑文字内容。
- **本机字体**：能选择本机已安装字体；支持多字体回退（主字体缺字时按序回退）；设备不支持时降级为手动输入字体名。
- **一致性**：画布与导出图片使用同一字体渲染。

### 3.5 自由图片

- **添加**：能把本地图片加到页面上；也能直接使用从其它程序复制的图片。
- **变换**：能方便又精准地移动、缩放（可选锁定比例）、旋转图片。
- **裁剪**：能裁掉图片任意一边，且随时可恢复原内容。
- **效果**：支持不透明度、模糊、亮度、色相、透明度渐隐（可指定方向与范围）。
- **互不影响**：同一张图片用在多处时，各处效果独立，互不干扰。

### 3.6 自由图形

- **类型**：能提供基本装饰图形（方形、菱形）。
- **可调**：尺寸、形状角度、颜色、实心/边框、圆角（含内凹圆角）。
- **效果**：支持与图片相同的效果（不透明度、模糊、亮度、色相、渐隐）。

### 3.7 背景

- **每页独立**：每页有自己的背景 = 填充色 + 任意数量图片或图形叠放；改一页不影响其它页。
- **背景图适配**：背景图支持多种填充方式（原大小 / 横向占满 / 竖向占满 / 最适合 / 自定义位置）；页面尺寸变化时自动调整。
- **背景效果**：背景图片与图形支持同自由图片/图形的位置与效果能力。
- **全局背景**：能把某一页的背景应用到所有页面；修改来源页实时同步到所有页；可随时取消，各页恢复自己的背景。
- **复制背景**：能把其它页的整份背景复制到当前页。
- **预置背景库**：内置一批免费预置背景（分主题分类、离线可用），可一键应用到当前页；也支持使用本地图片作背景。
- **边界**：背景始终被页面边界裁切，不参与内容排版、不触发内容溢出警告。

### 3.8 输出

- **尺寸**：能按指定像素尺寸导出 PNG（默认页面尺寸，可锁定宽高比放大）。
- **范围**：能导出当前页，也能一次导出所有页（多页打包为单个文件）。
- **内容**：能导出完整页面，也能导出仅含歌单内容、透明背景的版本（便于二次合成）。
- **一致性**：导出结果与画布所见一致，不包含任何编辑辅助（边框、参考线、警示、工具栏等）。

### 3.9 保存与迁移

- **自动保存**：编辑自动保存在本机，刷新或重新打开页面即可继续，无需手动保存。
- **项目导出**：能导出项目文件用于备份、跨设备/跨浏览器迁移；文件自包含（图片数据内嵌），不依赖原始文件。
- **项目导入**：能导入项目文件恢复并继续编辑；旧版本项目文件可打开并自动迁移。
- **资产去重**：相同图片只保存一份，项目文件不冗余。

---

## 4. 整体体验要求

- **性能**：画布操作与参数调整响应流畅，无可见卡顿。
- **撤销**：常见操作可撤销。
- **隐私**：全部数据留在本机，不上传；打开页面不依赖网络。
- **可访问性**：主要流程可用键盘完成；界面内容可被读屏工具理解。
- **浏览器**：支持 Chrome（85+）。

## 5. 范围之外与后续规划

- **未决（先问，不擅自定）**：打印/物理尺寸与 DPI；公开版的发布方式与首次使用引导；品牌名。
