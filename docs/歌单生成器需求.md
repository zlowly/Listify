# 歌单生成器
## 技术栈
纯网页版本 html+js

## 歌单输入
通过打开本地文件方式导入文本文件格式的歌单，文件可以是BOM或无BOM，GBK或UTF的
歌单暂定格式如下

```
#分类1
歌名1
歌名2 
#分类2
歌名3
歌名4 
```
- 第一个#前的歌名都分到“未分类”，分类和歌名不允许重名（报错提醒）
- 歌名前后空白忽略
- 重复导入则覆盖
- 不考虑增加序号

## 界面
- 左上边是歌单分类列表，仅显示分类名，不显示歌名，无法编辑
- 右边是歌单编辑画面
- 左下是对应歌单里不同选择对象的属性
歌单主要目标是手机分享图，因此数值单位都按像素，可以是多页（歌单编辑上方通过标签页来增删切换），缺省纵向页面,可设置页面大小和上下左右边距(通过输入数值或直接页面上拖拉)

## 歌单像PSD图片一样分图层
目前仅实现歌单层和背景层两层

###  歌单层
每个分类可拖拉进歌单层形成一个作为容器的方块区，方块区缺省宽度就是歌单层宽度，高度随内容动态变化。当超出页高度可溢出页外但进行溢出警告。
方块区里分类名和歌名为两个子分区，每个分区可指定自己的行间距、字体、大小、粗细、颜色，字体用本机字体
这两个缺省横向占满，分类名子分区在上，歌名子分区在下
歌名子分区内还可以划分成若干个指定了行列的表格
分区、子分区、表格等只是用来辅助定位，只在编辑时可见边框、输出到图片时不可见。

#### 表格的属性
- 列数(必须>0)
- 行数（填0则为动态，例如21个首歌而列数固定为5则为5行）
- 上下左右边距（各表格独立，px，默认 0，上下边距相加；左右边距相对分类块边缘内缩）
- 歌名排列规则(按字数从左往右逐列从上往下铺/按字数从上往下逐行从左往右铺)。注意对于多语言字母如中英混合的歌名的字数计算，如一个中文字数相当于两个英文字母。
- 当表格里一列有不同长度歌名时，以最长的歌名宽度做对齐规则（左对齐/居中/右对齐/拉伸字间距两边对齐）
- 列宽可选自动（缺省）和手动。自动时先量出每列最长歌名的显示宽度（含左右内边距和安全余量）a_i；令 n=列数，g=(表格宽度-Σa_i)/(n-1)，前 n-1 列宽为 a_i+g，最后一列为 a_n，剩余宽度全部变成等距列间距，最后一列贴右；g 是内容盒之外的独立间距，对齐/两端对齐只在 a_i 内进行。Σa_i 超过表格宽度时 g=0，退回按比例压缩并红格警示；单列直接占满表格宽度；自动间距不设上限。手动时可自行拖动列边，拖动后冻结当前列宽（含自动间距）、自动间距规则不再生效，当列过小导致歌名显示不完整，则歌名所在内容盒底色变红进行警示
歌名按表格属性铺满所有表格，当表格可容纳数量满了，自动铺到下一个表格，如果下方无表格，则自动创建新表格，表格属性复制上一个但行数为0（动态）

#### 自由图片
歌单层可以放置自由图片，图片属于当前页，不影响其它页。
- 图片始终铺满自己的宽高矩形，没有填充模式（cover/contain/stretch），不留白、不裁切；需要裁切时先在外部工具处理好再导入
- 位置和宽高可数值输入，也可在画布上选中后拖动、拖手柄缩放
- 只有一个“缩放时保持比例”开关：开启时任意手柄都按图片比例缩放；关闭时四个角手柄可自由拉伸，左右/上下边手柄只改一个方向
- 旋转用度数输入，任意角度，绕图片中心旋转；选择框、手柄和点击命中都跟随旋转
- 透明度和模糊（px）；模糊只在图片可见区域内生效
- 旋转后的图片按四个角判断是否超出页面

### 背景层
通过打开本地文件方式加载背景层图片。每页一个背景；新增页面时可选空白背景，或引用上页背景。
引用不是复制：引用页和上页共享同一份背景，之后任意一页修改图片、尺寸模式、透明度、模糊或填充色，同一组的所有页面实时同步。引用页可以“断开引用”变成独立副本；删除被引用的页面时，引用页保留当前画面并自动变成独立副本。
####背景层属性
- 主标题: 自由文本元素，带字体大小颜色位置等必要属性，可直接在页面上通过拖拉等方式编辑调整
- 图片本地路径
- 大小：原大小/横向占满/竖向占满/最适合（即居中放大到横竖向都刚好有画面）
- 透明度
- 边缘模糊（px）
- 颜色（未填满时）

## 输出
### 可保存为项目
- 项目保存格式为本地json文件，背景图片转base64
- 项目可重新加载继续编辑
### 可导出为图片
- 输出为指定大小的PNG图片
