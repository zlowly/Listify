# 歌单生成器
## 技术栈
纯网页版本 html+js

## 歌单输入
通过打开本地文件方式导入文本文件格式的歌单，文件可以是BOM或无BOM，GBK或UTF的
歌单暂定格式如下

```
#分类1
歌名1
歌名2 
#分类2
歌名3
歌名4 
```
- 第一个#前的歌名都分到“未分类”，导入完成后分类名与歌名唯一：同名分类会合并到第一次出现的分类，重复歌名保留第一次出现、后续行跳过并在确认时提示（不自动改名，也不追加序号）
- 歌名前后空白忽略
- 重复导入则覆盖
- 不考虑增加序号

## 歌单输出
左侧分类工具条在「导入歌单」旁提供「导出歌单」按钮；拖入 .txt 的提示不再以常驻文字呈现，改为 `?` 图标加浮动提示（悬停或键盘焦点时显示“也可以直接把 .txt 文件拖入分类区域导入”）
- 有歌单时：把当前歌单导出为 .txt 文本文件（歌单.txt），格式与输入格式相同，分类与歌名按当前存储顺序输出；“未分类”输出为显式的 `#未分类` 行；空分类只输出分类名行
- 导出的文本可通过「导入歌单」重新导入并还原出相同的分类与歌名；已放置的分类块只更新歌名数据，位置、样式、表格与列宽设置保留
- 没有歌单时点击「导出歌单」会提醒目前没有歌单，并询问是否要导出歌单模板；确认后导出样例歌单（歌单模板.txt）：包含“流行”“摇滚”两个分类，每个分类各 4 首歌名，内容符合上述格式规则

## 界面
- 左上边是歌单分类列表，仅显示分类名，不显示歌名；分类和歌名通过工具栏的「编辑歌单」弹窗修改
  - 弹窗左侧切换分类，右侧修改当前分类名，并以多列网格显示歌名；可新增、修改、删除歌名，也可在添加行粘贴多行文本（空行、以 `#` 开头的行和重复歌名会被跳过）
  - 不支持新增或删除分类；分类名不能为空且不能重名，歌名不能为空、不能以 `#` 开头且不能与其它歌名重复
  - 修改在点击「应用」后才写回；分类改名会同步到所有页面中已放置的分类块，并保留其位置、尺寸、样式和表格/列宽设置；点击「取消」不写回任何修改
- 右边是歌单编辑画面
- 左下是对应歌单里不同选择对象的属性
歌单主要目标是手机分享图，因此数值单位都按像素，可以是多页（歌单编辑上方通过标签页来增删切换），缺省纵向页面,可设置页面大小和上下左右边距(通过输入数值或直接页面上拖拉)

## 歌单像PSD图片一样分图层
目前仅实现歌单层和背景层两层

###  歌单层
每个分类可拖拉进歌单层形成一个作为容器的方块区，方块区缺省宽度就是歌单层宽度，高度随内容动态变化。当超出页高度可溢出页外但进行溢出警告。
方块区里分类名和歌名为两个子分区，每个分区可指定自己的行间距、字体列表、大小、粗细、颜色，字体用本机字体；字体列表按顺序回退，至少保留一项
这两个缺省横向占满，分类名子分区在上，歌名子分区在下
新建分类块时，分类名和歌名分别沿用同页上方最近同类型块的文字样式；同页没有上方块时取最近块，再退到项目文档顺序中最后一个块。继承是创建时的快照，不复制位置、宽度、显示开关、表格或后续修改
新建自由文字时，沿用上一个自由文字的完整文字样式（字体列表、字号、粗细、颜色、行距、对齐、阴影、轮廓），来源优先级与分类块相同；只继承样式，不复制文案、位置、宽度和层级，之后修改来源文字不影响已创建的文字
歌名子分区内还可以划分成若干个指定了行列的表格
分区、子分区、表格等只是用来辅助定位，只在编辑时可见边框、输出到图片时不可见。

#### 表格的属性
- 列数(必须>0)
- 行数（填0则为动态，例如21个首歌而列数固定为5则为5行）
- 上下左右边距（各表格独立，px，默认 0，上下边距相加；左右边距相对分类块边缘内缩）
- 歌名排列规则(按字数从左往右逐列从上往下铺/按字数从上往下逐行从左往右铺)。注意对于多语言字母如中英混合的歌名的字数计算，如一个中文字数相当于两个英文字母。
- 当表格里一列有不同长度歌名时，以最长的歌名宽度做对齐规则（左对齐/居中/右对齐/拉伸字间距两边对齐）
- 列宽可选自动（缺省）和手动。自动时先量出每列最长歌名的显示宽度（含左右内边距和安全余量）a_i；令 n=列数，g=(表格宽度-Σa_i)/(n-1)，前 n-1 列宽为 a_i+g，最后一列为 a_n，剩余宽度全部变成等距列间距，最后一列贴右；g 是内容盒之外的独立间距，对齐/两端对齐只在 a_i 内进行。Σa_i 超过表格宽度时 g=0，退回按比例压缩并红格警示；单列直接占满表格宽度；自动间距不设上限。手动时可自行拖动列边，拖动后冻结当前列宽（含自动间距）、自动间距规则不再生效，当列过小导致歌名显示不完整，则歌名所在内容盒底色变红进行警示
歌名按表格属性铺满所有表格，当表格可容纳数量满了，自动铺到下一个表格，如果下方无表格，则自动创建新表格，表格属性复制上一个但行数为0（动态）

#### 自由图片
歌单层可以放置自由图片，图片属于当前页，不影响其它页。
- 可通过“添加图片”选择本地文件，也可在画布上直接按 `Ctrl + V`（macOS 为 `Cmd + V`）粘贴剪贴板里的图片；粘贴始终新建图片，不会替换当前选中的图片
- 一次粘贴多张图片时会全部添加，并按 24px 依次错开，最后一张处于选中状态
- 图片始终铺满自己的宽高矩形，没有填充模式（cover/contain/stretch），不留白、不裁切；需要裁切时先在外部工具处理好再导入
- 位置和宽高可数值输入，也可在画布上选中后拖动、拖手柄缩放
- 只有一个“缩放时保持比例”开关：开启时任意手柄都按图片比例缩放；关闭时四个角手柄可自由拉伸，左右/上下边手柄只改一个方向
- 旋转用度数输入，任意角度，绕图片中心旋转；选择框、手柄和点击命中都跟随旋转
- 透明度和模糊（px）；模糊只在图片可见区域内生效
- 调色：亮度 50%–150%（默认 100%）、色相 -180°–180°（默认 0°）；调色属于图片条目而不属于图片资产，同一资产被多张图片引用时互不影响，也不改写资产数据
- 透明度渐隐：关闭/单向/双向，参数比照 Kdenlive 的 Alpha Gradient，包括位置、转场宽度、角度、顶部透明度、底部透明度（位置/宽度按角度轴的图片投影长度取 0%–100%，两端透明度 0%–100%）。
  - 单向：位置是渐变起点、转场宽度是坡长，坡可以伸出图片外；顶部/底部透明度是坡两端的不透明度；默认位置 0%、宽度 100%、顶部透明度 0%、底部透明度 100%，即旧的“从不透明铺满到全透明”。
  - 双向：位置是不透明带中心、转场宽度是不透明带宽度，带被夹在图片内，上下两条坡因此可以不等长；两端透明度作用于坡的外端；默认位置 50%、宽度 0%、顶部透明度 100%、底部透明度 100%，即旧的“两端透明、中点不透明”。
  - 切换模式会把位置、转场宽度与两端透明度重置为该模式的默认值，角度保留；双向时「转场宽度」在面板中显示为「不透明区宽度」。
  - 渐隐角度 0–360°，0° 为自上而下、顺时针递增，方向相对图片自身，图片旋转时随之旋转；最终不透明度 = 基础透明度 × 渐隐系数
- 效果合成顺序为模糊 → 调色 → 渐隐；渐隐只改透明度，不改变颜色、矩形、旋转、层级和点击命中，完全透明的区域仍可选中
- 亮度、色相、渐隐模式、渐隐位置、转场宽度、渐隐角度与两端透明度默认隐藏，由属性面板「外观」分组标题右侧的「高级」开关展开；开关只是本次会话的界面状态，不写入项目、不参与渲染、不触发重绘、切换时不修改数值；选中图片存在非默认效果值时，开关旁显示「已调整」提示
- 旋转后的图片按四个角判断是否超出页面

#### 自由图形
歌单层可以放置自由图形，图形属于当前页，不影响其它页；图形不引用图片资产。
- 通过画布左侧浮动工具条的「添加图形」进入绘制状态，光标固定为十字、不随下方元素变化；在页面内拖拽即按拖拽矩形创建，单击（拖动距离小于约 6px）则插入 240×240 的默认图形，并以点击位置为中心、自动夹在页面内。
- 一次激活只创建一个图形：创建后工具立即退出并选中新图形，属性面板直接显示其图形属性，便于改色与调其它参数；每次创建只产生一步撤销。按 Esc、再次点击入口、切换页面、在页面外按下或选中其它对象都会取消工具且不创建图形。拖拽预览只是编辑辅助，不写入导出图片。
- 画布左侧浮动工具条的「添加图形」始终添加到歌单层；页面背景分组的「＋ 图形」始终添加到背景层。两个入口互不推断当前选择；图形工具激活后切换入口会直接切换落点。当前落点的入口按钮显示按下态，被全局背景覆盖的页只能从工具条添加到歌单层，背景卡片不提供编辑入口。工具激活时用提示说明当前落点。
- 图形有两种形状：方形与菱形。方形使用外接矩形的宽高与直角；菱形以外接框四边中点为顶点，宽高是两条对角线，属性面板可输入 0–90° 的内夹角。角度由宽高推导，不单独保存；输入角度时保留长边、改变短边，90° 为正方形，0° 时短边最小为 1px；修改宽高后角度自动更新。
- 填充方式为实心或边框。实心填充整个图形；边框绘制在图形路径内侧，可见厚度等于「边框厚度」，不会超出外接框。圆角、边框颜色、几何在两种模式间切换时保留。
- 圆角为带符号值：0 为直角，正数为向外凸的圆角半径，负数为在每个角向内切出的圆弧缺口（内凹）。正数上限为内切圆半径；负数上限矩形为短边的一半、菱形为边长的一半。形状、角度或尺寸变化后自动夹取到合法范围。
- 位置、宽高、旋转可数值输入，也可在画布上拖动、拖八个手柄缩放、绕中心旋转；缩放不锁定宽高比，旋转后对侧锚点保持不动。
- 不透明度、模糊（在外接框内生效）、亮度 50%–150%、色相 -180°–180° 与透明度渐隐（单向/双向、位置、转场宽度、角度、顶部/底部透明度）与自由图片使用同一套范围、默认值、模式切换和合成顺序（模糊 → 调色 → 渐隐）；效果只作用于该图形，不改变几何与点击命中。
- 点击命中按实际绘制路径判断，菱形外接框的空白角、正圆角外侧与负圆角的内凹缺口都不会误选中。
- 删除、方向键微调、图层上下移与拖拽换序与自由图片一致；选中标题与删除确认文案使用「图形」。

### 背景层
背景属于页面：每页拥有自己的填充色与有序条目列表，条目可以是图片或图形，二者可任意交错叠放。项目不再维护背景库，也没有背景命名、使用页数与页面到背景的引用。

- 全局背景：任意页可勾选「所有页使用此背景」，项目记录一个全局来源页；后设置覆盖先设置，只保留最后一个。来源页背景的修改立即影响所有页面渲染，但各页自己的背景数据不变。取消全局后不记忆上一个全局，各页恢复显示自己的背景。
- 只读约束：全局生效且当前页不是来源页时，该页背景只读——更换背景、添加/替换/删除图片、添加/删除图形、排序、填充色、定位、调色与渐隐、复制背景、预置整套/加图/替换、拖入图片、画布拖动/缩放/旋转与方向键微调都被拒绝。页面背景分组的「＋ 图片」「＋ 图形」也不显示。页面只显示本页背景缩略图、全局来源页说明、取消全局入口与「本页接管」勾选，不展示被禁用的背景编辑按钮；接管不需要额外确认。
- 复制背景：可从任意其它页把整页背景（填充色 + 全部图片与图形及其定位、顺序、效果）复制到当前页；复制后所有条目 ID 重新生成，图片资产共享。
- 新增页面复制当前有效背景作为自己的独立背景；删除全局来源页自动取消全局，一次撤销恢复页面与全局记录；清空背景得到白底，图片与图形一起清空。
- 背景层始终位于歌单层下方；正常编辑时画布点击不会选中背景，需先在图层中选中背景、某张图片或某个图形后才能拖动、缩放、旋转；被全局覆盖的页不可进入背景编辑。
- 每张背景图片可独立设置大小：原大小/横向占满/竖向占满/最适合/自定义。前四种以页面中心为基准并随页面尺寸变化重排；自定义使用固定矩形，可旋转和等比缩放。直接拖动适配模式的图片会自动转为自定义。
- 每张图片独立设置透明度、边缘模糊和绘制顺序；图片与图形共用同一有序列表，顺序可在右侧属性面板、或图层面板的条目子行用上移/下移按钮调整，也可直接拖动子行换位，一次调整只产生一步撤销；填充色位于所有条目下方。
- 每张背景图片同样支持亮度 50%–150%、色相 -180°–180° 与透明度渐隐（单向/双向、位置、转场宽度、角度 0–360°、顶部/底部透明度），参数与默认值、模式切换规则和合成顺序（模糊 → 调色 → 渐隐）与自由图片一致；渐隐只改透明度，背景图仍被页面边界裁剪，渐隐不会让内容画到页面外。
- 背景图形同样支持独立的填充方式、颜色、带符号圆角、边框厚度、不透明度、模糊、亮度、色相与渐隐，参数与自由图形一致；图形与图片一样受页面边界裁剪。
- 背景图片的调色与渐隐控件默认隐藏，由「显示」分组标题右侧的「高级」开关展开；开关为会话级界面状态，不写入项目；存在非默认值时开关旁显示「已调整」。复制背景、替换图片和应用预置素材都保留已设置的数值。
- 预置素材：整套应用替换当前页背景（建议填充色 + 该图），已有背景图形一并清除，不再创建或复用「预置·X」背景集；加图与替换模式只作用于图片条目，图形保持不变。
- 解码失败、缺失资产和导出加载失败按原有规则报错；背景图片不参与内容溢出警告。
- 主标题（背景层自由文本）尚未实现，留作后续需求。

## 输出
### 可保存为项目
- 项目保存格式为本地json文件，背景图片转base64
- 当前项目版本为 5。背景使用统一的 `items` 有序列表，图片条目 `kind` 为 `image`、图形条目 `kind` 为 `shape`；版本 5 不再写出旧的 `background.images`。旧版应用不能读取版本 5。
- 版本 1–4 的项目可继续导入，加载时自动迁移到版本 5；版本 4 及更早的 `background.images` 按原顺序转换为 `kind:'image'` 的条目。
- 图片调色与渐隐字段在项目版本 3 及以后的版本中为可选：旧项目缺少字段时按默认值（亮度 1、色相 0、渐隐关闭、角度 0；位置/宽度/两端透明度按当前渐隐模式的预设）加载，保存时写出明确字段
- 项目可重新加载继续编辑
### 可导出为图片
- 输出为指定大小的PNG图片
