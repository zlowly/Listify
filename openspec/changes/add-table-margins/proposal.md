# Proposal

## Why

表格目前始终贴齐分类块左右边缘，且相邻表格之间没有任何间距；用户只能移动整个分类块，无法单独给某张表格留白，也无法让表格相对页面左右边距再缩进。结果是多表格分类块的歌名区域挤成一片，缺少视觉分组。

## What Changes

- 每个表格新增独立的 `margins: { top, right, bottom, left }`，单位为 px，非负，默认全为 `0`；默认值保证旧项目和现有布局完全不变。
- 表格左/右边缘相对分类块左右边缘内缩，表格可用宽度为 `W = 块宽 - left - right`；列宽、对齐、分隔线、红格都在 `W` 内重新计算，最后一列贴齐表格右边缘（即相对块右边再缩进 `right`）。
- 表格纵向堆叠加入上下边距：首表顶部 = 标题底部 + 表格上边距；后续表格顶部 = 上一表底部 + 上一表下边距 + 本表上边距（相加，不做 margin collapse）。
- 分类块高度把末表下边距计入占用高度；因此末表下边距既形成块内留白，也影响后续拖入分类块的堆叠位置和页面溢出警告。
- 表格属性卡片新增“上/右/下/左”四个边距输入，修改后立即重排；边距按表格独立保存，新增表格和自动续表复制上一表边距。
- 项目 JSON 保存/加载持久化 `margins`；旧项目缺失该字段时按全 `0` 读取，不升级项目版本。
- 当 `left + right` 过大时，表格宽度保底 40px 并继续留在分类块内，边距输入本身不做静默改写。
- `js/layout.js` 的 `devChecks()` 增加边距默认值、左右缩进、纵向相加、块高和极端边距断言。
- 同步 `docs/歌单生成器需求.md` 的表格属性说明。

第一版不做：在画布上拖拽调整表格边距（仅数值输入）、负边距、相邻表格边距折叠、表格背景/外框样式、导出格式变化。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `category-layout`: 表格新增独立的四边边距，参与表格宽度、纵向堆叠、分类块高度和自动续表属性复制。

## Impact

- `js/model.js`: `createTable` 增加默认 `margins`，新增边距归一化辅助。
- `js/layout.js`: 表格宽度与 `x/y` 按边距计算；块高计入末表下边距；`normalizeTables`、`addTable`、`devChecks` 更新。
- `js/render.js`: 表格边框、红格、列分隔线与命中区域使用每张表自己的 `x`。
- `js/ui.js`: 表格卡片增加四边距输入并绑定重排。
- `js/io.js`: 序列化/反序列化与校验兼容 `margins`（旧文件缺省为 0）。
- `style.css`: 表格卡片内边距输入的紧凑布局。
- `docs/歌单生成器需求.md`: 表格属性补充上下左右边距。
- 不引入构建、依赖或运行时网络；仍是 `file://` 可打开的静态页面。
