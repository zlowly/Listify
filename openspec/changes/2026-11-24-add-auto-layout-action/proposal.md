# Proposal

## Why

当前“自动排版”只在单张表格内做动态行与自动续表，无法把同一个分类的歌名按视觉宽度拆成多张列数不同的表格。用户手工提高容量时依赖“前几行多一列、后面少一列”的多表结构，而现有 UI 只能逐表增删、手填行列数。

算法层的 `L.layout.arrangeTables` 已实现并通过回归，但还没有 UI 入口。直接把自动拆表作为新增分类块的缺省动作，会在效果尚未验证时改变所有既有用户的排版结果，风险过高。

## What Changes

- 在分类块属性面板「表格」组顶部新增“自动布局”操作区：最多行数、密度（20%–100%）两个参数与「自动布局」按钮。
- 点击按钮 SHALL 先弹出确认框，明确“保留字体、对齐与表格边距，清除当前所有表格的列数、行数、列宽与多余表格，并按歌名重新分割”，并说明可撤销。
- 确认后调用 `L.layout.arrangeTables`，用结果替换 `element.tables`，写入撤销栈，并只刷新属性面板的表格组；MUST NOT 作为新增分类块、拖入分类或导入歌单的缺省动作。
- 无法排版（存在过长歌名/宽度不足）时提示且不修改模型；结果超过“最多行数”时仍应用并提示实际行数；大分类走单表简化时提示。
- 参数只保存在本次会话（不写入项目文件），项目格式与数据结构不变。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `category-layout`：新增“分类块自动布局”需求——手动触发、确认后可撤销、在给定最多行数与密度下把一个分类拆成多张列数不同的表格，不改变字体，失败/超预算/简化有明确反馈。

## Impact

- `js/ui-property-panel.js`：表格组新增自动布局行、参数读取、确认框、结果提示与表格组局部刷新。
- `js/app.js`：新增 `autoLayoutCategory(element, options)` 意图方法（撤销快照 + 替换 `element.tables` + 排程重绘），并从 `L.app` 导出。
- `style.css`：自动布局参数行的少量样式。
- `js/layout.js`：不新增改动，复用已实现的 `arrangeTables`。
- `scripts/checks/layout.test.js`：算法层已覆盖；本变更不新增项目格式或纯逻辑分支。
