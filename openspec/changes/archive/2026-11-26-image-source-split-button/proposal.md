# 提案：添加图片分裂按钮（本地文件 / 粘贴剪贴板 / 预设图库）

## Why

画布工具条的「添加图片」按钮目前只有一个本地文件入口，粘贴（Ctrl+V）与预设图库分别藏在快捷键和背景弹窗里，可发现性差。改为分裂按钮（split button）后，一个按钮聚合三个图片来源，与画图软件的工具箱交互对齐；同时画廊内重复的「本地图片」入口可以去除，来源选择统一收敛到工具栏。

## What Changes

- 「添加图片」按钮改为分裂按钮：
  - 主按钮执行「上次使用的来源」（默认本地文件），图标与 `aria-label` 随来源更新；
  - 主按钮旁增加窄箭头区，点击向右弹出菜单（`role="menu"`），列出 本地文件 / 粘贴剪贴板 / 预设图库；
  - 菜单项以 `role="menuitemradio"` 标注当前默认来源；点击菜单项执行该来源并记忆为新的默认。
- 「预设图库」复用现有画廊弹窗（`ui.openPresetPicker`），不新建弹窗。
- 画廊弹窗内移除「本地图片」整行入口（`createLocalRow` 及其错误回退分支中的引用）；拖入图片文件的链路保持不变。
- 「粘贴剪贴板」菜单项复用现有粘贴插入管线（与 Ctrl+V 同一链路）。
- 不在本变更内（后续迭代）：「添加图形」的同类分裂按钮（方形/圆形/椭圆/直线）。

## Capabilities

### New Capabilities

- `image-source-menu`：添加图片的来源分裂按钮——主按钮执行上次来源、箭头弹出来源菜单、菜单语义与键盘导航、来源记忆。

### Modified Capabilities

- `editor-shell`：
  - 「画布浮动工具条」：添加图片按钮成为分裂按钮，插入区出现箭头子按钮与向右弹出菜单；
  - 「背景库弹窗」：弹窗内不再提供「本地图片」整行按钮（本地文件来源改由工具栏分裂按钮提供）。

## Impact

- `index.html`：`btn-add-image` 外层增加 `.tool-split` 结构、箭头按钮与菜单 DOM（与示范文件 `/tmp/listify-splitbtn-demo.html` 一致）。
- `style.css`：分裂按钮与向右弹出菜单样式（取色与工具栏现有变量对齐）。
- `js/ui.js`：箭头/菜单的事件绑定、键盘导航与外部关闭。
- `js/app.js`：`insertImage` 拆分为三个来源入口；来源记忆状态（内存内，不写入项目文件）。
- `js/ui-pickers.js`：移除 `createLocalRow` 及其调用与错误回退文案中的本地入口措辞。
- 兼容性：`file://` 运行环境下 `navigator.clipboard.read()` 可能不可用，粘贴菜单项需降级为提示使用 Ctrl+V（见 design）。
- 无持久化格式变化；`scripts/checks` 纯逻辑回归不受影响，index.html 脚本清单不变（无新增文件）。
