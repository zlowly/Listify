# Proposal

## Why

自由图片目前用 cover / contain / stretch 三种“填充模式”描述图片如何放进固定框，这和用户实际调整图片的方式不一致：用户想要的是移动、缩放图片本身，而不是选择一种摆法。这个固定框模型还挡住了旋转，并让属性面板比实际需要更复杂。

同时，新页“沿用上页背景”当前是一次性复制。之后源页改了背景，沿用页不会跟着变；用户的本意是让沿用页**引用**源页背景，任何时候都保持一致。

## What Changes

- **BREAKING** 自由图片不再有 `fit`（cover / contain / stretch）属性。图片始终铺满自己的宽高矩形，没有裁切、没有留白、没有“框内摆图”。
- 自由图片新增 `keepRatio`（默认开启）：开启时任何缩放手柄都保持比例；关闭时角手柄可自由拉伸，左右/上下边手柄只改单轴。
- 自由图片新增 `rotation`（单位度，任意角度，默认 0），绕元素中心旋转。选择框、手柄、命中测试都跟随旋转。
- 自由图片新增 `blur`（px，默认 0）；保留 `opacity`。
- 不做裁剪：不引入裁剪模式、源裁剪矩形或四边裁剪手柄。需要裁切的图片由用户在外部工具处理好再导入。
- 缩放与旋转联动：拖动任意手柄时，对侧锚点在页面空间保持不动；开启 `keepRatio` 时由图片自身比例约束元素矩形。
- 溢出警告按旋转后的四个角判断，不再只看未旋转的矩形。
- 旧项目（v1）的 `fit` 在加载时近似迁移：`stretch` 保留矩形且不锁比例；`contain` 缩到完整图片矩形且锁比例；`cover` 扩到覆盖矩形且锁比例。**cover 原本隐藏的裁切区域无法还原**，这是去掉填充模式的已知代价。
- 背景层保持现状：每页一个 `background` 对象，四种尺寸模式、透明度、模糊和填充色都不变。
- 新页“沿用上页背景”从复制改为**实时引用**：新页的 `backgroundRef` 指向当前页背景的所有者；所有引用页共享同一份背景，任意一页修改尺寸模式、图片、透明度、模糊或填充色，其它引用页立即同步。
- 引用页提供“断开引用”操作，断开后复制当前背景为独立副本；删除被引用的页面时，引用页自动物化当前背景为独立副本，保持画面不变。
- 项目 JSON 版本升级到 2：新增 `keepRatio`、`rotation`、`blur`、`backgroundRef`；加载 v1 时按上面的规则迁移。

第一版明确不做：裁剪、任意形状蒙版、旋转手柄（只用数值输入角度）、自由图片的“仅横向/仅纵向”三态缩放、把背景层改成普通内容元素。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `page-editor`: 自由图片从三种填充模式改为“铺满矩形 + 等比锁 + 任意旋转 + 模糊”；缩放/命中/溢出行为随旋转更新；新页背景来源从复制改为引用。
- `background-layer`: 跨页共享背景的语义从“复制设置、之后独立”改为“实时引用、始终一致”，并定义断开引用与删除源页后的行为。
- `project-persistence`: 图片元素字段改为 `keepRatio` / `rotation` / `blur`（移除 `fit`），背景支持引用关系，项目版本升级并兼容 v1。

## Impact

- `js/model.js`: 图片元素默认值、背景引用解析、旧 `fit` 迁移辅助。
- `js/render.js`: 旋转、模糊、铺满矩形绘制；命中测试与溢出判断支持旋转。
- `js/app.js`: 缩放手柄与锚点、旋转后的拖拽、新页引用背景、删除页面时物化引用。
- `js/ui.js`: 自由图片属性面板（等比、角度、模糊）；背景面板显示引用状态与断开引用。
- `js/io.js`: 序列化/校验/版本迁移；背景引用读写。
- `style.css`: 属性面板少量布局，无新框架。
- `docs/歌单生成器需求.md`: 同步图片与背景引用说明。
- 不引入构建、依赖或运行时网络；仍是 `file://` 可打开的静态页面。
