# Proposal

## Why

右侧属性面板目前只用一条 1px 虚线加 11px 灰色标题分隔各大类。分类块属性里「分类名子分区」和「歌名子分区」的标题与字段样式完全相同，字段又多（字体列表、字号、粗细、颜色、行距、阴影、轮廓），滚动时很容易把上半区的字段看成下半区的，误改样式；整块子分区也无法收起，改表格时不得不在长面板里反复滚动。另外「粗细」下拉把「常规 400」这类内部数值暴露给用户，并占满整行，字号被迫单独占一行。

## What Changes

- **分组边界强化**：属性面板的每个分区由虚线分隔改为独立卡片（1px 实线边框 + 纸白底 + 分组标题条），分组之间留白加大；子分区标题提升到 12px 主墨加粗，并保留组内字段的缩进节奏，使「分类名子分区」「歌名子分区」在扫读和滚动中一眼可辨。
- **分组折叠**：每个分区标题变为可折叠开关（标题按钮 + 朝向箭头 + `aria-expanded`），点击或键盘 Enter/Space 收起/展开整块内容；折叠状态在当前选择对象上保持，属性面板因改值重渲染后不丢失。
- **隐藏分类名自动折叠**：关闭「显示分类名」时，分类名子分区自动收起；用户仍可手动展开以调整保留的样式；重新开启「显示分类名」时自动展开。
- **粗细只显描述、与字号同行**：粗细选项去掉 `300/400/700` 数值后缀，只保留「细体 / 常规 / 中等 / 半粗 / 粗体 / 特粗 / 黑体」；下拉按内容定宽（不再整行），与「字号」放入同一行。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `editor-shell`：「右侧属性检查栏」增加分组卡片化、分组折叠与折叠状态保持、分类名子分区随隐藏自动折叠、粗细仅显示文字描述并与字号同行的可观察行为。

## Impact

- `js/ui.js`：分组标题渲染改为统一的 `propGroup` 构建函数（标题按钮 + 内容容器）；新增面板级折叠状态存储与切换绑定；`renderCategoryProperties` 的显示开关事件驱动折叠；`weightOptions()` 标签去掉数值；`categoryStyleFields` 把字号与粗细并入同一行。
- `style.css`：`.prop-group` 由虚线分隔改为卡片；新增分组标题按钮、箭头、折叠体、窄下拉样式；调整字段行在卡片内的内边距与行距。
- `DESIGN.md`：Property Inspector 章节补充卡片化分组与折叠约定（实现阶段同步）。
- 不改项目数据结构、不新增依赖、零构建与 `file://` 约束不变；属性面板不参与 PNG 导出，导出结果不受影响。
