# Spec Delta

## ADDED Requirements

### Requirement: 对齐参考线的视图一致性

对齐参考线 SHALL 与元素、选择框和手柄使用同一套页面到屏幕坐标变换；缩放或滚动后，参考线 MUST 仍贴合它所表示的元素边线，MUST NOT 因视图变化而偏移。参考线的显示与清除 MUST NOT 改变缩放比例、滚动位置或元素几何，也 MUST NOT 参与命中测试。指针释放后不得残留上一次拖动的参考线。

#### Scenario: 放大后吸附对齐

- **WHEN** 画布处于 200% 且用户拖动分类块吸附到页面左边距
- **THEN** 参考线与页面内容区左边的屏幕位置重合，分类块左边缘也贴合该位置

#### Scenario: 滚动后吸附对齐

- **WHEN** 用户滚动到页面下半部分后拖动分类块吸附到另一分类块的下边
- **THEN** 参考线显示在用户看到的目标边线上，不因滚动偏移而离开该边线

#### Scenario: 参考线不参与命中

- **WHEN** 用户点击一条正在显示的对齐参考线
- **THEN** 命中测试按参考线下方的元素或页面处理，参考线本身不被选中

#### Scenario: 不改变视图状态

- **WHEN** 用户完成一次带吸附的拖动
- **THEN** 缩放比例与滚动位置保持拖动前的值

#### Scenario: 松手后无残留

- **WHEN** 用户松开指针并继续缩放或滚动画布
- **THEN** 上一次拖动的对齐参考线不随视图变化重新出现或停留在画布上
