# Spec Delta

## ADDED Requirements

### Requirement: 列分隔线对齐吸附

拖动列分隔线时，系统 SHALL 把该分隔线的页面 x 坐标吸附到同一分类块内其它表格的列分隔线、其它分类块表格的列分隔线，以及页面内容区左右边缘。吸附 SHALL 使用与分类块吸附相同的屏幕像素阈值、最近目标、每轴一条和 Alt（Option）关闭规则。吸附只 SHALL 调整分隔线两侧相邻列的宽度，表格总宽、列数、填充顺序、对齐方式与表格边距 MUST NOT 改变。若目标会使相邻任一列宽低于 24px，系统 MUST 忽略该目标并继续允许自由拖动。

#### Scenario: 同块跨表列对齐

- **WHEN** 同一分类块有上下两张表，用户拖动下表的列分隔线，使其距上表对应分隔线 4px
- **THEN** 下表分隔线吸附到上表分隔线，两表该列边界在页面中重合

#### Scenario: 跨块列对齐

- **WHEN** 用户拖动一个分类块内的列分隔线，使其接近另一分类块内某条列分隔线
- **THEN** 分隔线吸附到另一块的对应分隔线，两块的该列边界在页面中重合

#### Scenario: 吸附页内容区边缘

- **WHEN** 用户拖动列分隔线，使其距页面内容区右边 5px
- **THEN** 分隔线吸附到页面内容区右边，参考线贴在页面内容区边缘

#### Scenario: 最小列宽保护

- **WHEN** 某个吸附目标会使分隔线左侧或右侧的列宽低于 24px
- **THEN** 该目标被忽略，分隔线继续跟随指针自由移动，不强制跳到目标

#### Scenario: 总宽不变

- **WHEN** 用户拖动分隔线并吸附到目标
- **THEN** 分隔线左侧列宽增加的量等于右侧列宽减少的量，表格总宽保持不变

#### Scenario: 不改变表格结构

- **WHEN** 用户完成一次列分隔线吸附拖动
- **THEN** 表格列数、行数、填充顺序、对齐方式和四边距保持不变

#### Scenario: 拖动后进入固定列宽

- **WHEN** 用户在自动列宽的表格上拖动分隔线并吸附到目标后松手
- **THEN** 该表按既有规则转为固定列宽，松手后的列宽和分隔线位置保持吸附结果
