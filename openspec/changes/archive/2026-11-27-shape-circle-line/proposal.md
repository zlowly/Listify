# 提案：图形工具增加圆形与直线

## Why

图形工具目前只支持方形与菱形。歌单排版中常见的圆形装饰（印章感、圆点）与直线（分隔线、下划线）需要借助图片或方形拼凑。在既有形状框架上补齐这两种基础形状，并加入画图软件惯例的 Ctrl 约束绘制，成本低、收益直接。

## What Changes

- 形状种类扩展：`SHAPE_KINDS` 增加 `circle`（圆形）与 `line`（直线），属性面板「形状」下拉同步出现 圆形/直线 选项——**直线也出现在形状下拉中，已有图形可直接切换为直线**。
- 圆形：
  - 与方形一样支持 实心/边框（`mode`）与颜色、边框厚度；拖拽绘制时在预览矩形内画椭圆；
  - 单击（未拖动）插入默认尺寸的正圆。
- 直线：
  - 采用**框随方向**模型：线段以 长度（`width`）、线粗（`height`，与 `strokeWidth` 同步）与方向（`rotation`）描述，线段恒为框的水平中线，外接框随方向旋转；`mode` 对直线仅保留边框语义；
  - 选中的线段显示两个端点手柄，拖拽端点即调整长度与方向；属性面板显示 长度/角度；
  - 单击（未拖动）插入默认长度的水平线段；
  - 新增「两端渐尖距离」参数（`taper`，整数像素，默认 0）：大于 0 时线段两端各在指定距离内由完整线粗线性收窄至端点成尖，0 表示恒定线粗不变。
- Ctrl 约束绘制（**Ctrl = 约束，默认自由**）：
  - 圆形拖拽时按住 Ctrl → 外接框取正方形 → 正圆；
  - 直线拖拽时按住 Ctrl → 方向吸附到 45° 步进（0/45/90/…/360），松开 Ctrl 恢复自由；
  - 拖拽过程中实时响应 Ctrl 的按下与松开。
- 不改变：现有方形/菱形行为、图形效果（模糊/调色/渐隐）、落点规则、吸附与撤销粒度。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `shape-tool`：
  - 「图形类型与默认值」：种类清单加入圆形与直线，补默认值；
  - 「实心与边框」：圆形继承实心/边框语义，直线仅边框语义；
  - 「图形绘制工具」：拖拽绘制支持圆形/直线预览，新增 Ctrl 约束（正圆、45° 方向）；
  - 「图形选择与变换」：直线的缩放/旋转按外接框语义说明。

## Impact

- `js/shape.js`：`SHAPE_KINDS`、`DEFAULT_SHAPE`、圆角/边框上限（直线的 inradius 语义）、命中判断、直线 `taper`/`flip` 字段的归一与夹取。
- `js/render.js`：`traceShape` 增加圆/椭圆与对角线路径；直线渐尖改为按锥形多边形填充渲染。
- `js/project-io.js`：两处 `shape === 'diamond' ? ... : 'rect'` 白名单改为四值白名单。
- `js/app-interactions.js`：`shape-draw` 拖拽增加 Ctrl 约束（沿用 `bindSnapModifier` 的修饰键监听模式），单击默认值按形状区分。
- `js/ui-property-panel.js`：形状下拉加入圆形/直线；直线隐藏圆角字段、显示两端渐尖距离输入；提示文案。
- `scripts/checks/`：shape.js 纯逻辑回归补新形状用例。
- 兼容性：项目数据新增 `shape` 枚举值，旧版本读取含 circle/line 的项目会回落为 rect（既有白名单行为延续），本变更不提供向后写兼容。
