# Spec Delta

## ADDED Requirements

### Requirement: 适应窗口的纵向留白

适应窗口模式下，页面 SHALL 在画布可视区内居中且完整可见。适配比例仍取“可用宽度约束”和“可用高度约束”的较小值；当高度约束决定适配比例时，上下留白 MUST 每侧不超过 16px，使竖版页面按高度尽量铺满画布。左右留白 MAY 保留独立的呼吸空间。上下留白 SHALL 同时用于适配比例、页面居中位置和舞台尺寸的计算，且 MUST NOT 使适应窗口产生滚动条。

#### Scenario: 竖版页面铺满纵向空间

- **WHEN** 页面为 1080×1920，画布可视区高度为 844px，视图处于适应窗口模式
- **THEN** 页面显示高度不小于 812px，页面上下各留白不超过 16px，页面水平居中

#### Scenario: 适应窗口无滚动条

- **WHEN** 竖版页面按新的上下留白完成适配
- **THEN** 页面完整显示在可视区内，横向和纵向都不出现滚动条

#### Scenario: 窗口尺寸变化后重新铺满

- **WHEN** 用户在适应窗口模式下改变浏览器窗口高度
- **THEN** 适配比例随之重算，页面仍居中且上下留白每侧不超过 16px

#### Scenario: 宽版页面保持水平留白

- **WHEN** 页面为横版且由宽度决定适配比例
- **THEN** 页面按宽度约束缩放并水平居中，左右留白沿用原有比例，页面不产生滚动条

#### Scenario: 固定比例不受影响

- **WHEN** 用户从适应窗口切换到 150% 固定比例
- **THEN** 页面按 150% 显示，滚动范围按固定比例计算，适应窗口的留白规则不再参与
