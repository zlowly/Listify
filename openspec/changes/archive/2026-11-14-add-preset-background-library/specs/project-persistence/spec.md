# Spec Delta

## ADDED Requirements

### Requirement: 预置物化持久化
预置素材应用后 SHALL 物化为普通图片资产，按现有图片资产规则存储、去重、释放与导出；项目 MUST NOT 依赖应用随附的预置清单；同一预置被多个元素或多个背景使用时 SHALL 只保存一份；物化资产不再被任何内容元素或背景引用时 SHALL 按现有规则释放。

#### Scenario: 自包含
- **WHEN** 用户应用某预置后导出项目
- **THEN** JSON 包含该图片的完整 base64 数据，在未携带同版本预置清单的环境加载与导出均正常

#### Scenario: 物化往返
- **WHEN** 应用预置的项目保存后重新加载
- **THEN** 预置图片及其定位、不透明度、模糊与保存前一致

#### Scenario: 物化释放
- **WHEN** 删除某背景后其物化资产不再被引用
- **THEN** 导出的 JSON 不再包含该资产
