# Proposal

## Why

背景图片目前只能来自用户上传的本地文件：App 不提供任何现成素材，用户要做出好看的背景必须自己找图、下载、导入。对只想快速出图的用户这是一道不必要的门槛。预置一批免费（CC0/自制）的背景与叠层素材，在选背景的同一入口里一键套用，即可直接得到可交付的观感。

## What Changes

- 新增预置素材库：14 个预置（10 个背景图 + 4 个透明图），以内嵌 base64（data: URL）形式打包在 `js/presets-data.js`；清单含稳定 ID（只增不改不删）、名称、kind（背景图/透明图）、建议填充色、默认定位（背景图 cover / 透明图 original）、默认不透明度、缩略图、来源与许可。
- 新增统一的"选择背景图"弹窗：分类标签（全部/背景图/透明图）+ 预置缩略图网格 + 网格末尾虚线"本地图片"瓦片（点击选文件/支持拖入）；纯色不入弹窗。清单懒加载：首次打开弹窗才注入 `js/presets-data.js`（约 3.5MB），不进首屏。
- 三个入口统一打开同一弹窗，**入口决定模式、内容决定来源**：
  - 页面属性 `[选择背景图]`（整套）：点预置新建/复用自动命名背景集"预置·X"并指派当前页（全局模式开启时指派 `unifiedBackgroundId`，不覆写各页 `backgroundId`）；
  - 图层面板 `＋`（加图）与图片属性面板"替换图片"（替换）：保留现有语义，预置同样可选。
- 点击即应用 + toast，无二次确认；建议填充色为深色时 toast 提示可调亮歌名文字颜色，不修改任何数据。
- 物化机制：应用时将清单 base64 转 blob 并走现有资产管线（`addFile`，按内容 hash 去重），背景图片条目照常引用产生的资产 ID；模型与持久化零改动，项目 JSON 自包含。
- 本地图片沿用现有用户手势文件选择/拖拽读取链路，行为不变。
- 弹窗底部新增"更多免费素材"指引链接行：Pixabay/Unsplash/Pexels/OpenGameArt（均经 2026-11 GreatFire 实测确认中国大陆可不受限直连），新标签页打开，应用自身不发起网络请求；链接列表为静态常量，便于增删。
- `build.sh`：版本注入扩展到 `js/presets.js` 中的懒加载引用串（`js/presets-data.js` 位于 `js/`，拷贝自动覆盖）。
- `README`：素材来源与许可 credits，并增加"推荐素材库"一节；`docs/preset-gallery-mockup.svg` 布局稿已更新。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `background-layer`：预置素材清单与懒加载、统一"选择背景图"弹窗、预置应用行为（入口 × 内容矩阵）、深色背景提示、物化进现有资产管线。
- `project-persistence`：预置物化后等同普通资产（hash 去重、未引用释放、嵌入导出），项目自包含可加载可导出。
- `release-build`：`js/presets-data.js` 进入产物并参与版本注入（懒加载引用串）。

## Impact

- 代码：新增 `js/presets.js`（懒加载器 + 弹窗状态）、`js/presets-data.js`（开发时生成的数据文件）；改动 `js/ui.js`（弹窗 + 三入口）、`js/app.js`（应用处理器）；`build.sh` 增加注入行；不新增运行时依赖。
- 数据：项目 JSON 结构不变（预置图片物化后成为普通资产）；使用过预置的项目 JSON/草稿体积增加对应素材大小（hash 去重后每个素材只存一份）。
- 素材：新增 `presets/` 开发目录（CC0 原始图 + 自制素材生成脚本 + 打包脚本）；许可均为 CC0 或自制，无运行时网络请求。
- 约束：零构建、`file://` 可开、无 CDN、无新依赖不变；`file://` 下 canvas 污染导致导出挂起的风险已通过实测排除（素材走 base64→blob 链路）。
