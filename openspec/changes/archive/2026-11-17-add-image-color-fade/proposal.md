# Proposal

## Why

图片（自由图片与背景图）目前只能调透明度与模糊。用户想让照片更亮、换个色调，或者把图片边缘融进背景色里，只能先跑到外部软件处理好再重新导入——这既打断排版节奏，也让"调一下看看"的成本高到一个不可能试错的地步。这两件事本质上是两个数值参数，做成画布内的可撤销调整，才能真正被用起来。

## What Changes

- 图片（自由图片与背景图，逐张独立）新增两个调色参数：**亮度**（0.5–1.5，默认 1）与**色相**（-180°–180°，默认 0）。
- 图片新增**透明度渐隐**：关闭 / 单向（不透明→透明）/ 双向（透明→不透明→透明），可指定 0–360° 角度；角度坐标**相对图片自身**，图片旋转时渐隐随之旋转。最终不透明度 = 基础透明度 × 渐隐系数。
- 模糊、调色与渐隐在同一张图的处理结果里合成：模糊先生效，渐隐再作用其上；背景图仍被页面边界裁剪。
- 这些控件默认隐藏。属性面板对应分组（背景图「显示」、自由图片「外观」）标题右侧提供一个**「高级」开关**；开关只控制控件可见性，**不参与渲染**——已有非默认值的图片在开关关闭时仍照常绘制，并在开关旁显示“已调整”提示，避免用户误以为效果丢了。
- 新参数以**可选字段**加入现有项目结构，项目版本仍为 3：旧项目打开时取默认值，新项目文件在旧构建里只丢失这两个面板的显示能力而不破坏加载。保存、草稿、撤销、复制背景、替换图片、预置应用 SHALL 完整保留这些参数。
- 渲染侧把现有模糊缓存扩展为统一的图片处理缓存（模糊 + 调色 + 渐隐一次烘焙，按尺寸分桶 + 像素预算 + 拖拽冻结）：**缓存命中后的每帧成本与今天相同**，只有参数变化或首次绘制才付一次烘焙代价。导出复用同一管线，并按全分辨率出图（不因缓存降采样而变糊）。
- **不做**：背景填充色渐变、渐变色叠加层、对比度/饱和度/色温等其余调色参数、渐隐深度（终点不透明度）微调。

## Capabilities

### New Capabilities

- `image-effects`: 图片调色与透明度渐隐的语义与适用范围——参数范围与默认值、渐隐的角度/单向/双向/图片局部坐标定义、与基础透明度及模糊的合成顺序、非破坏性与替换/复制时的保留规则，以及"效果随项目保存与导出逐像素一致"的可观察结果。

### Modified Capabilities

- `background-layer`: 「背景图片透明度、模糊与绘制顺序」扩展到调色与渐隐；「背景图片编辑」与「预置加图与替换」的"替换保留字段"清单加入新参数，保证换图不重置观感。
- `page-editor`: 「自由图片」要求自由的图片也支持调色与渐隐，并与旋转、透明度、模糊共存。
- `png-export`: 「完整内容与裁剪」明确完整页面导出包含调色与渐隐效果；仅歌单层因不含任何图片而不受影响。
- `project-persistence`: 「往返一致」的可保存字段清单加入调色与渐隐；导入旧项目（版本 1–3、无这些字段）时取默认值且不视为损坏。
- `canvas-view`: 「背景层与内容层更新解耦」与「页面装饰层与几何测量更新时机」枚举的滑条类型加入调色、渐隐角度与渐隐模式，明确调整它们不重算内容层文字布局、不重绘装饰层、不重做溢出检测。
- `editor-shell`: 「右侧属性检查栏」增加高级开关的位置与两处面板的一致性；新增一条开关行为要求（默认隐藏、应用级内存态、只控制可见性、有非默认值时自动呈现展开、开关状态不写入项目）。

## Impact

- `js/model.js`：`DEFAULT_BACKGROUND_IMAGE`、`createImageElement`、`cloneBackgroundImage` 增加 4 个字段与取值范围常量。
- `js/project-io.js`：`serializeElement` 与 `serializeBackgroundImage` 显式写出新字段（该文件是逐字段手写序列化，漏写即静默丢数据）。
- `js/project-schema.js`：新字段的可选校验（缺失合法、越界报错）。
- `js/render.js`：`blurredImage` 扩展为处理缓存（缓存键、滤镜串、`destination-in` 渐隐掩膜、导出时的高分辨率分支、掩膜按页面交集裁剪）；`drawFreeImage`、`drawBackground` 接入。
- `js/app.js` / `js/app-backgrounds.js`：字段白名单、面板回写意图方法、重绘层次（背景只动 `bg`，自由图片动 `content`）。
- `js/ui-property-panel.js` / `js/ui-fields.js` / `style.css`：两处「显示/外观」分组的控件与「高级」开关。
- 测试：`scripts/checks/model.test.js` 覆盖默认值、克隆保真、序列化往返、旧项目默认值；掩膜与缓存属绘制行为，用 `agent-browser` 核对。
- 文档：`docs/歌单生成器需求.md` 与 `README.md` 的图片/背景能力描述同步。
- 无新增依赖、无构建步骤变化、无运行时网络请求。
