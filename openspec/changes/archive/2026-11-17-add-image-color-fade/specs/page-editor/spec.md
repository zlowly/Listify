# Spec Delta

## MODIFIED Requirements

### Requirement: 自由图片
系统 SHALL 允许在内容层添加本地图片；图片 SHALL 始终铺满自身宽高矩形，并支持位置、宽高、等比缩放锁定、任意角度旋转、透明度、模糊、亮度与色相调色、以及透明度渐隐；系统 MUST NOT 提供填充模式或裁剪，渐隐 SHALL 只改变透明度，MUST NOT 改变图片的填充方式或裁切范围；图片 SHALL 每页独立。

#### Scenario: 添加图片并 cover
- **WHEN** 用户添加一张本地图片
- **THEN** 图片按原始比例放入页面并铺满元素矩形，等比锁定开启，旋转为 0，模糊为 0；不再有 cover 模式

#### Scenario: 切换 contain
- **WHEN** 用户在图片属性中查找填充模式
- **THEN** 系统不提供 contain/cover/stretch；图片始终铺满矩形，需要完整显示时调整宽高

#### Scenario: 铺满矩形
- **WHEN** 图片元素宽高比与其原始比例不同且等比锁定关闭
- **THEN** 图片拉伸铺满整个元素矩形，不裁切、不留白

#### Scenario: 等比锁定
- **WHEN** 等比锁定开启时拖动任一手柄
- **THEN** 元素宽高按图片原始比例同步变化，图片不变形

#### Scenario: 旋转图片
- **WHEN** 用户把旋转角度设为 30 度
- **THEN** 图片绕元素中心旋转 30 度绘制，选择框与手柄跟随旋转

#### Scenario: 透明度和模糊
- **WHEN** 用户设置透明度和模糊值
- **THEN** 图片按设置半透明并模糊，模糊只作用在图片可见区域内

#### Scenario: 调色
- **WHEN** 用户把某张自由图片的亮度设为 130%、色相设为 20°
- **THEN** 该图片变亮并偏色，元素几何与同页其它元素不变

#### Scenario: 渐隐
- **WHEN** 用户为某张自由图片开启双向渐隐
- **THEN** 图片上下两端淡出到透明，中部保持当前透明度，页面背景从淡出区域透出

#### Scenario: 替换图片
- **WHEN** 用户替换图片且等比锁定开启
- **THEN** 元素宽度保持，高度按新图片比例调整，中心位置不变，调色与渐隐设置保留
