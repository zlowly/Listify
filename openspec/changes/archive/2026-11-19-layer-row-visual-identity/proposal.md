# Proposal

## Why

图层视图里所有图片行共用同一个 `▧` 图标和「图片」字样，图形行也不显示自身颜色；一页放多张图片或图形时，列表行彼此无法区分，用户只能靠点选后在画布上反复试错确认身份。

## What Changes

- 内容图片行与背景图片子行的图标位改为该图片资产的缩略图，直接复用已有资产 blob URL；资产缺失或 URL 不可用时回退为现有 `▧` 字形。
- 内容图形行与背景图形子行的图标改为按 `shape.color` 着色的迷你图形，并区分实心（`fill`）与描边（`stroke`）两种填充方式。
- 内容图片行与背景图片子行增加序号标签（`图片 N`），让同类行有一个稳定的口语锚点。
- 背景条目子行的序号改为按同类计数：图片序号只数图片、图形序号只数图形（**BREAKING**：现有背景子行按全部条目计数，混排时编号会变化；排序、选择、拖拽语义不变）。
- 缩略图与迷你图形保持纯装饰：不改变行高、内边距、字号与悬停样式，不进入行的无障碍名称，也不新增任何持久化数据。

## Capabilities

### New Capabilities

- 无：本次只调整既有图层视图行的呈现，不引入新的系统能力。

### Modified Capabilities

- `editor-shell`: 图层视图的行内标识变化——图片行显示缩略图、图形行显示自身颜色、图片行显示同类序号；行尺寸、焦点、选中、拖拽与换序行为维持现状。

## Impact

- 代码：`js/ui.js` 的 `renderLayerPanel`（行 HTML 拼装）与 `style.css` 的 `.layer-icon` 及新增标记样式；不新增文件，`index.html` 脚本顺序不变。
- 数据读取（只读）：`L.assets.getUrl` / `getMeta` / `getCachedImage`、`element.assetId`、`shape.color` 与 `shape.mode`；项目 JSON、草稿库、资产库、导出流程与项目 schema 均不改动。
- 行为差异：背景条目子行的标签编号在「图片与图形混排」时改变；`图片 N` 对内容图片是新增标签；不影响排序结果与撤销记录数量。
- 回退路径：资产缺失、缩略图加载失败、图形不透明度极低或颜色过浅时，行仍需可辨认且不破坏行尺寸。
- 验证：`node --test scripts/checks/*.test.js` 不覆盖 DOM 与画布，本变更依赖浏览器人工验证与 `agent-browser` 自动化检查。
