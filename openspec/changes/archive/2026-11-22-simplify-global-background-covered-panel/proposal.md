# Proposal

## Why

被全局背景覆盖的页面原先在背景分组底部额外显示「全局背景 / 本页接管」勾选，与上方「取消全局背景」并存，容易被理解成当前页还有一个独立的全局开关；来源说明「显示第 X 页的全局背景」又放在缩略图旁，与取消动作分离。把被覆盖页收敛为「查看来源 + 取消全局」一条路径，可以减少控件与误解。

## What Changes

- 被全局背景覆盖的页面背景分组移除「全局背景 / 本页接管」勾选行，只保留本页背景缩略图与「取消全局背景」按钮。
- 来源说明从缩略图旁移到「取消全局背景」按钮之后，文案改为「目前全局背景为第 X 页的背景」，其中 X 为来源页序号。
- 被覆盖页的拒绝编辑提示统一改为「请先取消全局背景。」，不再提及「让本页接管」。
- 接管全局改为两步：先取消全局背景，再在本页勾选「全局背景」。
- 全局指针语义、撤销、草稿持久化、画布渲染、图层面板与导出行为均不变。

## Capabilities

### New Capabilities

- 无。本次只调整既有背景分组的被覆盖页展示与提示。

### Modified Capabilities

- `background-layer`: 修改被覆盖页的只读控件组成（移除「本页接管」）、来源说明的位置与文案，并同步「背景图片编辑」「全局背景覆盖」「预置整套应用」中被覆盖页提示的措辞。

## Impact

- 代码：`js/ui-property-panel.js` 的 `backgroundGroup` 被覆盖分支与 `bindBackgroundGroup`；`js/app.js`、`js/app-backgrounds.js`、`js/app-presets.js` 的拒绝提示；`style.css` 中与被覆盖页说明行相关的间距规则。
- 数据：无模型、schema、草稿或导出格式变更。
- 验证：`node --test scripts/checks/*.test.js` 应无回归；用 `agent-browser` 或手动走查被覆盖页面板结构、来源说明文案与序号、取消全局后的接管路径、拒绝编辑提示与撤销。
