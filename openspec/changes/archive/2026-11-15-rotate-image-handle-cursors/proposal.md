# Proposal

## Why

图片支持任意角度旋转，但缩放手柄的鼠标光标仍使用固定朝上的系统关键字（`ew-resize` / `ns-resize` / `nwse-resize` / `nesw-resize`），不随图片旋转。图片转到 45° 或 30° 后，悬停边界或四角时看到的光标与图片实际边界方向不一致，用户要靠试拖才确认方向，属于明显的“所见非所得”。

## What Changes

- 自由图片和背景编辑中选中的背景图片，其 8 个缩放手柄在悬停时 SHALL 显示与图片旋转角同步的光标方向：左右手柄跟随图片旋转角，上下手柄为旋转角 + 90°，四角手柄固定为旋转角 + 45°。
- 光标采用“预旋转的内联 SVG 光标”（`url(data:image/svg+xml,…)`，32×32、热点在中心、双向箭头），按旋转角生成并缓存；接近 0°/45°/90° 等标准方向时回退系统关键字，浏览器不支持 SVG 光标（或角度为 0）时同样回退到现有系统关键字。
- 旋转角改变后（属性面板输入、撤销/重做），即使指针不动，悬停手柄上的光标 SHALL 立即按新角度刷新。
- 非图片元素（分类块、自由文字）的左右手柄、页尺寸手柄、边距参考线、页面尺寸手柄等保持不变。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `page-editor`: 新增“旋转图片的缩放手柄光标”要求——八个手柄的光标方向随图片旋转角同步，四角固定 45°，并覆盖标准方向回退与不支持自定义光标时的行为。
- `background-layer`: “背景层位置”要求中“与内容图片使用同一套坐标与手柄命中规则”扩展为同时覆盖悬停光标规则，并补充旋转背景图的光标场景。

## Impact

- `js/app.js`：`imageHandlePoints()`（L710–731）需要按旋转角返回光标定义，`updateCursor()`（L924–951）与 `onPointerMove` 需要支持自定义光标；新增光标 SVG 生成与缓存辅助函数。
- 无需改动数据模型、项目 JSON、导入/导出或渲染几何；`computeImageResize()` 已按旋转角计算，拖拽逻辑不变。
- 不新增依赖，保持零构建；验证在浏览器中手动进行（旋转图片后悬停八个手柄），`agent-browser` 可断言 `overlay.style.cursor` 字符串。
