# Proposal

## Why

当前透明度渐隐只有「模式 + 角度」：单向永远铺满整张图，双向永远以中点为尖峰，用户无法像 Kdenlive 的 Alpha Gradient 那样控制渐变从哪里开始、坡有多宽、两端各留多少透明度。对于把照片边缘融进背景、或在图片中部保留一条清晰带这类排版需求，现有两三个档位不够用。

## What Changes

- 图片（自由图片与背景图，逐张独立）的渐隐新增四个参数，与 Kdenlive Alpha Gradient 对齐：**位置**、**转场宽度**、**顶部透明度**、**底部透明度**，加上已有的**角度**共五个可调参数。
- 单向：位置是渐变起点、宽度是坡长，坡可以伸出图片外（图片只采样其中一段）；顶部/底部透明度是坡两端的不透明度。
- 双向：位置是不透明带中心、宽度是不透明带宽度；不透明带被夹在图片内，两端各有一条坡，因此上下坡可以不等长；两端透明度作用于两条坡的外端。
- 切换渐隐模式时，位置/宽度/顶部/底部透明度重置为目标模式的预设（角度保留），避免把单向的 100% 坡长直接当成双向的 100% 不透明带。
- 属性面板高级区新增四个滑条，双向时「转场宽度」标签显示为「不透明区宽度」；模式字段附 `?` 提示说明切换会重置参数。
- 新字段以可选字段加入项目结构，版本仍为 3：旧项目按当前渐隐模式的预设加载，保存后写出明确数值；缓存键、PNG 导出与副本/替换逻辑同步覆盖新字段。
- **不做**：Kdenlive 的 Operation 合成方式、背景填充色渐变、逐像素颜色叠加、渐隐色调。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `image-effects`: 透明度渐隐从「模式 + 角度」扩展为五个参数；定义单向/双向的几何、默认值与模式切换规则、越界校验与旧项目兼容。
- `project-persistence`: 往返字段清单与旧项目默认值加入位置、转场宽度、顶部/底部透明度。
- `background-layer`: 背景图片的逐图渐隐参数同步扩展，并明确不影响填充色与其它图片。
- `canvas-view`: 调整新滑条时仍只重绘对应层，不重算内容层文字布局。
- `editor-shell`: 高级区新增四个渐隐控件及其标签/禁用/提示行为。
- `page-editor`: 自由图片支持新的渐隐参数，几何与命中不变。

## Impact

- `js/model.js`：新增范围常量、模式预设、`fadeValues` / `fadeDefaults` / `fadeProfile`，默认背景图与自由图片补字段。
- `js/render.js`：渐隐掩膜改为读取 `fadeProfile` 的渐变向量与色标；处理缓存签名加入四个参数。
- `js/project-schema.js`：新字段可选校验与按模式补齐默认值。
- `js/project-io.js`：自由图片/背景图序列化与加载补齐字段（逐字段白名单）。
- `js/ui-property-panel.js`：高级区新增位置、转场宽度、顶部/底部透明度控件；模式切换重置参数。
- `js/app.js`：自由图片字段白名单加入四个字段。
- 测试：`scripts/checks/model.test.js` 覆盖默认值、模式预设、单向/双向几何与副本保留；`scripts/checks/io.test.js` 覆盖校验、旧项目默认值与往返。
- 文档：`docs/歌单生成器需求.md`、`README.md` 同步；无新增依赖、无构建步骤变化。
