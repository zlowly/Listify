# Proposal

## Why

背景层即将支持"添加文字"后，内容层与背景层的能力集合趋同，但两者的插入入口分散在画布工具栏（内容层）与属性面板背景分组（背景层），交互位置与方式不统一，增加认知负担。需要把插入工具统一收敛到画布工具栏，并补齐背景层文字能力。

## What Changes

- 画布顶部工具栏的插入区分为"内容层 / 背景层"两组，各含 文字 / 图片 / 图形 三个按钮；每个按钮自身声明落点层，不引入落点切换控件，工具栏成为插入操作的唯一入口。
- 新增背景层文字能力：背景条目新增 `kind: 'text'`（固定页面坐标矩形，同背景图形的定位语义），支持添加、选中、属性编辑、删除、换序、随"复制背景 / 清空背景"整体复制与清空。
- 属性面板"页面背景"分组的"＋ 图片 / ＋ 图形"按钮移除（插入统一走工具栏）；分组保留更换/预置、复制背景…、清空背景、全局开关等非插入操作。
- 背景图形工具的落点由所点按钮直接决定（内容层图形钮 / 背景层图形钮），复用现有 armed 状态与 `aria-pressed` 按下态。
- 被全局背景覆盖的非来源页：工具栏背景组三钮禁用并提示先取消全局背景；来源页正常可用。

## Capabilities

### New Capabilities

（无——背景文字归入既有 `background-layer` 能力，不单独开新能力。）

### Modified Capabilities

- `background-layer`：新增背景文字条目（模型、渲染、编辑、换序、复制/清空、导出）；移除属性面板"＋图片/＋图形"插入入口，插入入口统一为画布工具栏背景组。
- `shape-tool`：落点不再由切换状态决定，改为由所点工具栏按钮（内容层/背景层）直接决定；按下态同步到背景层图形按钮。
- `page-editor`：画布工具栏插入区新增"内容层/背景层"两组按钮的布局、禁用与提示要求。

## Impact

- 代码：`index.html`（工具栏按钮）、`js/model.js`（`kind:'text'` 条目创建/克隆/校验）、`js/app.js`（背景加字/加图处理器、armed 落点、全局覆盖禁用）、`js/ui.js`/`js/app-chrome.js`（事件绑定与按钮状态）、`js/ui-property-panel.js`（移除插入钮、背景文字属性字段）、`js/render.js`/`export.js`（背景文字渲染与导出）、`js/project-schema.js`（旧项目兼容读取）。
- 规范：`openspec/specs/background-layer`、`shape-tool`、`page-editor` 相应条款修订。
- 兼容性：项目 schema 需接受 `kind:'text'` 背景条目；旧版本项目文件读入不报错、行为不变。
- 测试：`scripts/checks/` 模型与 IO 回归新增用例。
