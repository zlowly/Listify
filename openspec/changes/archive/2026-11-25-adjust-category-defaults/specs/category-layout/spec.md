# Spec Delta

## ADDED Requirements

### Requirement: 新建分类块默认初始值

无继承来源时，新建分类块 SHALL 使用默认初始值：分类名字号 64px、歌名字号 32px，首张表格列数为 4。其他文字样式与表格属性 SHALL 沿用既有默认值。这些默认值 MUST 只作用于新建对象，MUST NOT 改写已有分类块、已保存项目的样式或复制上一表属性的新增表格。

#### Scenario: 拖入第一个分类

- **WHEN** 项目还没有任何分类块，用户把分类拖入页面
- **THEN** 新分类块的分类名字号为 64px、歌名字号为 32px，首张表格为 4 列动态行

#### Scenario: 有继承来源时不使用默认值

- **WHEN** 同页已有分类块的分类名 44px、歌名 28px，用户新建分类块
- **THEN** 新分类块继承来源块的 44px 与 28px，而不是 64px 与 32px

#### Scenario: 新增表格复制上一表列数

- **WHEN** 用户在一个 5 列的分类块中新增表格
- **THEN** 新表格保持 5 列，不套用默认的 4 列

#### Scenario: 旧项目保持不变

- **WHEN** 用户加载一个已保存的、分类名为 44px、歌名为 28px、首表 3 列的项目
- **THEN** 该分类块仍按已保存的样式和列数显示
