# Proposal

## Why

编辑器目前只能插入文字和图片，背景层也只能放图片；用户无法快速画出方形或菱形装饰块，也无法让图形与背景图片交错叠放。增加图形工具可以让用户用少量操作完成色块、边框、菱形点缀等常见歌单装饰，同时保持“导入即可用、少调”的产品方向。

## What Changes

- 新增图形元素：内容层的 `type: 'shape'` 元素，以及背景层的 `kind: 'shape'` 条目。
- 图形支持方形与菱形；菱形提供 0–90° 内夹角输入，角度由外接框宽高推导，改角度时保留长边、调整短边。
- 图形支持实心 / 边框两种填充方式、颜色、带符号圆角（正值外凸、负值内凹）与边框厚度；边框绘制在图形内侧。
- 图形效果与自由图片一致：透明度、模糊、亮度、色相、渐隐（单向 / 双向），并复用“高级”效果开关。
- 画布浮动工具条新增图形工具：拖拽绘制矩形；单击插入默认 240×240 图形；创建后工具保持激活，可连续绘制；`Esc`、再次点击按钮、切换页面或选中其他对象时退出。
- 图形落点由入口决定：画布工具栏的“添加内容图形”固定写入 `page.elements`；页面背景卡片另提供“＋ 图形”入口，固定写入 `background.items`。不再根据当前选择或背景编辑态推断目标层。
- 背景模型统一为 `background.items[]`，每项 `kind: 'image' | 'shape'`；图片与图形可任意交错，按 items 顺序从底到顶绘制。复制背景、清空背景、预置整套替换、全局背景、背景预览和只读约束都覆盖 items。
- 图层面板混排图片与图形，显示“图片 N · 图形 M”，支持同列表内拖拽换序；属性面板新增图形属性；删除确认与选中标题识别“图形”。
- 项目格式升级到版本 5；v1–v4 的 `background.images` 在加载时映射为 `kind: 'image'` 的 items；校验、序列化、草稿恢复和导出同步到 v5。
- 完整页导出包含内容图形与背景图形；仅歌单层导出仍只绘制分类块，不包含图形。
- 新增纯逻辑图形几何模块 `js/shape.js`，承载默认值、菱形角度 / 尺寸换算、内切圆与负圆角上限、路径与命中测试，便于 Node 回归测试。
- **BREAKING**：v5 项目 JSON 的背景使用 `items`，不再写 `images`；旧版本应用无法读取 v5 项目文件，但新版本继续兼容读取 v1–v4。

## Capabilities

### New Capabilities

- `shape-tool`: 图形元素与背景条目的数据模型、方形 / 菱形几何、内夹角、带符号圆角 / 边框、效果、拖拽创建、内容 / 背景两种落点、选择与命中。

### Modified Capabilities

- `background-layer`: 背景从图片列表改为图片 / 图形统一的有序 `items` 列表；补充图形编辑、排序、复制、清空、预置整套替换、预览与全局只读行为。
- `editor-shell`: 工具条图形按钮、图层混排与计数、图形属性面板，以及背景 items 的拖拽列表语义。
- `page-editor`: 内容图形的选择、移动、缩放、删除、方向键微调与页面溢出规则与自由图片一致；背景层描述改为 items。
- `png-export`: 完整页导出包含内容图形与背景图形；仅歌单层导出排除图形。
- `project-persistence`: 项目版本 5、items 往返、v1–v4 迁移、草稿最大版本 5，以及项目文件背景结构更新。
- `code-architecture`: 新增纯逻辑 `shape` 模块并更新模块加载顺序、职责边界与 Node 测试范围。

## Impact

- 主要代码：`js/model.js`、新增 `js/shape.js`、`js/render.js`、`js/project-schema.js`、`js/project-io.js`、`js/draft-store.js`、`js/app.js`、`js/app-backgrounds.js`、`js/app-interactions.js`、`js/app-chrome.js`、`js/ui.js`、`js/ui-property-panel.js`、`js/export.js`、`index.html`。
- 项目文件格式 v5；v1–v4 兼容读取；草稿恢复版本上限 5；无新增网络请求、运行时依赖或构建步骤。
- 现有背景图片行为保持不变，仅数据容器由 `images` 变为 `items`；图形不引用图片资产，资产收集与清理只处理 image 条目。
- Node 纯逻辑测试补充菱形角度 / 尺寸、内切圆夹取、v5 往返、v4→v5 迁移与 schema 校验；画布交互和视觉效果用 `agent-browser` 手动验证。
