# Spec Delta

## MODIFIED Requirements

### Requirement: 歌名顺序
系统 SHALL 保存导入文件中的原始歌名顺序，直到用户对某个分类显式触发排序；排版时的虚拟字数排序 SHALL 作为独立计算步骤，不改变保存的原始顺序。重新导入 SHALL 用文件中的顺序覆盖该分类的存储顺序。

#### Scenario: 重导入改变顺序
- **WHEN** 新文件调换同一分类内两首歌的先后
- **THEN** 原始顺序更新，画布按排序规则重新排版

#### Scenario: 排序后重导入
- **WHEN** 用户对某分类排序后再导入同一文件
- **THEN** 该分类的存储顺序恢复为文件中的原始顺序
