## 4. 异常与兼容

- [x] 4.1 草稿损坏或版本过高：把原始值备份到 `listify.draft.corrupt`，打开空白项目并提示；验证：手动写入非法 JSON 后刷新，出现提示、corrupt 键保留、应用可继续使用。
- [x] 4.2 图片资产缺失：备份原始草稿，恢复其余页面、歌单和内容，移除缺失图片引用并提示数量；验证：删除 IDB 中一条资产后刷新，其余内容恢复且缺失图片被移除。
- [x] 4.3 存储不可用或配额失败：进入内存模式并显示状态，编辑和导出仍可用；验证：模拟 `localStorage.setItem` / IDB 写入抛错，走一次导入、编辑、导出流程。
- [x] 4.4 旧项目文件兼容：v1/v2/v3 JSON 仍按现有规则导入；验证：用现有导出的 v3 文件和手工构造的 v2 文件各导入一次，迁移后画面正确。
- [x] 4.5 多标签页：记录“最后写入者覆盖”为已知限制；如加入 `storage` 事件提示，验证另一标签页保存时当前页出现提示且不自动重载。
