# Proposal

## Why

图片目前只能整体显示，无法从原图里裁掉不需要的部分。背景图用 `cover` 只能按页面居中裁，自由图片只能拉伸或调整宽高，用户要得到局部画面只能先在外部工具裁好再导入。把裁剪做成图片自身属性后，裁剪值可反复调整、可撤销、随项目保存，且不破坏原始资产。

## What Changes

- 自由图片与背景图片新增「裁剪」：在图片属性「高级」中提供上/右/下/左四个数值，十字布局，单位是原图像素；缺省 0，可逐边调小或归零。
- 裁剪只决定可见区域，不修改原始资产。存储保留完整框与裁剪四边；可见矩形由两者推导。调小或取消裁剪时，被裁掉的像素在原位重新出现，不做重新适配。
- 可见矩形成为选择框、命中测试、缩放手柄、溢出提示、缩略图与渐隐等比例效果的参照。
- 模糊、亮度、色相、透明度仍作用于图片像素；模糊先按完整框烘焙再取可见子矩形，避免裁剪边缘出现透明晕。
- 背景图片的裁剪叠加在 fit 几何之后：`cover` 裁剪后不再铺满页面，边缘露出填充色；`fit` 切到 `none` 时烘焙当前完整框，裁剪值保持不变；页面尺寸变化时 fit 完整框重排，裁剪按原图像素跟随。
- 旋转轴固定为完整框中心；拖拽旋转时在画布显示轴心十字，松手后不常驻。
- 替换图片（自由图片、背景图、预置图）SHALL 把裁剪归零，其余效果保留。
- 选中图片且裁剪非零时，画布以虚线显示完整框、压暗被裁区域；属性面板与图层行显示「已裁剪」摘要，不常驻虚框。
- 项目 JSON 与草稿保存裁剪字段；旧文件缺少该字段时按 0 处理。

## Capabilities

### New Capabilities

- `image-crop`: 图片裁剪的数据与几何语义：原图像素坐标、完整框与可见矩形、可逆性、边界约束、与替换/旋转/命中的关系。

### Modified Capabilities

- `page-editor`: 自由图片不再禁止裁剪；可见矩形参与选择、命中、缩放与替换后的几何。
- `background-layer`: 背景图片支持裁剪；裁剪与 fit/自定义矩形、页面重排、替换、旋转轴和背景预览的关系。
- `image-effects`: 渐隐的位置/宽度/角度投影以裁剪后的可见矩形为参照；模糊按完整框烘焙再取可见区域。
- `editor-shell`: 图片属性「高级」中的裁剪控件、可见尺寸与「已裁剪」提示、旋转轴十字。
- `project-persistence`: 裁剪字段随项目与草稿往返；旧项目缺省为 0。
- `png-export`: 完整页面导出按裁剪绘制，裁掉的部分不出现，效果与画布一致。

## Impact

- `js/model.js`：新增裁剪归一化、完整框/可见框换算、裁剪后等比比例。
- `js/render.js`：图片与背景绘制按源裁剪矩形取样；模糊/渐隐烘焙改用完整框；缓存键加入裁剪；导出掩膜改用可见矩形。
- `js/app.js`、`js/app-backgrounds.js`、`js/app-interactions.js`、`js/app-chrome.js`：选择框、命中、缩放、旋转轴、fit→none 转换与替换路径改用可见矩形/完整框。
- `js/ui-property-panel.js`、`js/ui.js`：裁剪十字控件、可见尺寸摘要、已裁剪徽标、旋转轴十字。
- `js/project-io.js`、`js/draft-store.js`：裁剪字段序列化与缺省值。
- `scripts/checks/model.test.js` 等：补充裁剪换算、边界、可逆性与往返用例。
- 不新增运行时依赖，不改变零构建方式；不修改图片资产本身。
