# Spec Delta

## ADDED Requirements

### Requirement: 裁剪持久化

项目 JSON 与本地草稿 SHALL 为每张自由图片和背景图片保存上、右、下、左四个裁剪值；重新加载后裁剪值、可见矩形与画面 SHALL 与保存前一致；版本 1–5 的文件缺少裁剪字段时 SHALL 按 0 补齐并正常加载，再次导出后 SHALL 写出显式的裁剪字段；负数、非有限数或非数字裁剪值 SHALL 判为项目无效。

#### Scenario: 裁剪往返
- **WHEN** 用户给一张自由图片与一张背景图设置不同裁剪值后导出项目并重新加载
- **THEN** 两张图的四边裁剪值与可见画面与保存前一致

#### Scenario: 旧文件缺少裁剪
- **WHEN** 用户打开一个没有裁剪字段的版本 5 项目
- **THEN** 所有图片按裁剪 0 加载，项目可继续编辑

#### Scenario: 保存补齐字段
- **WHEN** 用户打开旧项目后直接导出
- **THEN** 导出的 JSON 中每张图片都含显式的上、右、下、左裁剪字段，数值为 0

#### Scenario: 非法裁剪值
- **WHEN** 项目文件中某张图片的裁剪值为 -5、字符串或非有限数
- **THEN** 系统提示项目无效并停止加载，当前项目保持不变
