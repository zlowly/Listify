# Proposal

## Why

分类名、歌名和自由文字目前的样式只有字体、字号、粗细、颜色和行距，无法做强调排版（如白字加深色阴影、描边突出歌名）。给字体加上阴影与轮廓设置，是低成本显著提升排版表现力的能力。

## What Changes

- 分类名子分区样式（`titleStyle`）和歌名子分区样式（`songStyle`）各新增独立的“阴影”和“轮廓”设置：
  - 阴影：开关、颜色、横向偏移、纵向偏移、模糊半径，渲染为投影在文字后方的整体阴影（任意偏移方向下阴影都不覆盖自身文字）；关闭时不绘制阴影。
  - 轮廓：开关、颜色、线宽；关闭时不绘制轮廓，绘制时描边在填充文字之下（先描边后填充），轮廓宽度与文字宽度解耦，不改变换行与列宽计算。
- 自由文字样式（`style`）同样新增独立的“阴影”和“轮廓”设置，参数与语义一致。
- 属性面板：在现有字体设置区（字号/粗细/颜色/行距之后）为三处文字样式分别增加“阴影”“轮廓”分组控件，带开关，默认关闭。
- 画布渲染与 PNG 导出均按新设置绘制；新字段随项目 JSON 保存与加载，旧项目加载时缺省为“关闭”，不要求用户重新设置。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `category-layout`: “子分区样式”要求扩展——分类名和歌名各自支持字体、字号、粗细、颜色、行距之外，还支持独立的阴影（开关、颜色、X/Y 偏移、模糊）与轮廓（开关、颜色、线宽）设置。
- `page-editor`: “自由文字”要求扩展——文字样式在字体、字号、粗细、颜色、行高、对齐和宽度之外，还支持独立的阴影与轮廓设置。

## Impact

- `js/model.js`：`DEFAULT_TITLE_STYLE` / `DEFAULT_SONG_STYLE` / `DEFAULT_TEXT_STYLE` 增加 `shadow`、`outline` 默认值；`normalizeStyle` 对新字段做容错归一（旧数据缺字段视为关闭）。
- `js/ui.js`：`categoryStyleFields` / `textStyleFields` 增加阴影、轮廓分组控件与绑定。
- `js/render.js`：`drawCategory`（标题与歌名）、`drawJustifiedText` 所在分支、`drawFreeText` 在 `fillText` 前按样式应用 Canvas 阴影/描边（描边先于填充）。
- 项目 JSON：三处文字样式对象新增可选字段；旧项目向后兼容（无字段 = 关闭），旧版本加载新项目时忽略未知字段即可。
- 不改变布局计算（换行、虚拟字数、列宽、行高均不受轮廓线宽影响）；不引入新依赖。
