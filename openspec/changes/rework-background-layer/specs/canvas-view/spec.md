# Spec Delta

## MODIFIED Requirements

### Requirement: 缩放与滚动后的坐标一致

缩放或滚动后，画布命中测试、选择框、缩放手柄、旋转手柄、边距参考线、列分隔手柄和行内文字编辑 SHALL 与页面实际显示位置对齐；点击、拖动和双击 MUST 落在用户看到的对象上；背景编辑状态下，背景图片的命中测试、选择框和手柄 SHALL 与内容元素使用同一套缩放/滚动坐标转换。

#### Scenario: 滚动后点选元素

- **WHEN** 用户滚动到页面下半部分并点击一个分类块
- **THEN** 被选中的正是该分类块，选择框贴合其显示位置

#### Scenario: 放大后拖动边距

- **WHEN** 用户在 200% 下拖动左边距参考线
- **THEN** 参考线跟随指针，属性面板中的左边距数值按页面坐标更新

#### Scenario: 滚动后双击文字

- **WHEN** 用户滚动并双击一个自由文字元素
- **THEN** 行内编辑框出现在该文字的显示位置，字号和换行与当前缩放一致

#### Scenario: 滚动后拖动背景图

- **WHEN** 用户选中一张背景图，滚动到页面下半部分后拖动它
- **THEN** 背景图跟随指针移动，选择框和手柄贴合其显示位置

#### Scenario: 放大后旋转背景图

- **WHEN** 用户在 200% 下旋转一张自定义背景图
- **THEN** 旋转手柄、选择框和图片角度同步，命中测试落在旋转后的可见区域

#### Scenario: 选择背景不重置视图

- **WHEN** 用户在固定比例和滚动位置下从图层选中一张背景图
- **THEN** 缩放比例和滚动位置保持不变
