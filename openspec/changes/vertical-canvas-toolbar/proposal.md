# Proposal

## Why

页面编辑工具条目前是一条横在画布顶部的浮动栏，占据画布区本就有限的垂直空间；而页面默认为 1080×1920 纵向，画布的横向空间相对富余。把工具条改为贴在画布左缘的竖条、按钮改为图标加悬停浮动提示，可以用富余的横向空间换取被工具条挤占的垂直空间，让页面在视口中的可见区域更大。

## What Changes

- **工具条改为竖向贴左缘**：画布浮动工具条从顶部横向改为贴在画布可视区左缘的竖向窄条，仍在画布区内浮动、不随内容滚动，不占独立整行。
- **按钮图标化**：新增页、删除页、添加文字、添加图片、缩小、放大、适应窗口等动作改为图标按钮；文字标签不再内联显示，改为在悬停或获得焦点时以浮动提示出现（“添加图片”的提示保留“也可 Ctrl+V 粘贴”说明）。
- **页签改为数字图标**：页面页签从横向文字条（“第 N 页”）改为数字图标页签（1/2/3…），悬停或获得焦点时以浮动提示显示“第 N 页”，当前页高亮。
- **缩放控件随条竖排**：缩小、可编辑百分比、放大、适应窗口四个控件保留，随竖条纵向排布，百分比仍为可编辑数值。
- **溢出改为竖向滚动**：页数超过工具条可视高度时，页签区竖向滚动，新增/删除/插入等动作保持可见；窄或矮画布下工具条仍贴左缘且不遮挡页面可编辑区。
- **画布适配改预留左侧空间**：画布“适应窗口”改为为左缘竖条预留水平偏移（而非顶部高度偏移），页面不被工具条遮挡。
- **行为不变**：导入解析、页面增删切换、添加文字/图片、缩放与滚动、导出 PNG、项目存取均不变；工具条与页签仍只属于编辑界面、不进入导出。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `editor-shell`: “画布浮动工具条”要求从顶部横向改为贴在画布左缘的竖向窄条，规定动作为图标按钮并以悬停/焦点浮动提示承载文字标签、页签用数字图标页签、页数过多时页签区竖向滚动。

## Impact

- `index.html`: 重排 `#canvas-toolbar` 的分组与顺序（页面 / 插入 / 缩放）以适配竖向布局，为浮动提示提供挂载结构。
- `style.css`: `.canvas-toolbar` 改为竖向 flex、贴左缘、固定窄宽；页签、图标按钮、缩放控件改纵向排布；新增浮动提示样式；调整窄宽度断点。
- `js/ui.js`: 页签改为数字图标页签渲染并绑定浮动提示；图标按钮保留原事件绑定。
- `js/app.js`: 画布适配时由“顶部工具条高度偏移”改为“左缘工具条宽度偏移”，页面内容不被竖条遮挡；不改页面/元素数据模型。
- `DESIGN.md`: 更新画布工具条位置、形态与图标/浮动提示约定的描述。
- 不引入构建、依赖、网络请求或新数据格式；仍是 `file://` 可打开的零构建静态页面。
