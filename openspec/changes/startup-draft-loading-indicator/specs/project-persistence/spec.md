# Spec Delta

## MODIFIED Requirements

### Requirement: 草稿启动恢复
打开编辑器时，系统 SHALL 在恢复本地草稿期间于画布中央显示载入提示，MUST NOT 同时显示「从左侧导入歌单」空态提示；载入提示 SHALL 在恢复结束（成功、无草稿或失败）后移除，并由恢复的内容或既有空态接管。系统 SHALL 自动恢复最近草稿并保持可继续编辑；没有草稿时 SHALL 打开默认空白项目；草稿损坏或版本不受支持时 SHALL 提示且不得静默加载；草稿引用的图片资产缺失时 SHALL 恢复其余内容并提示缺失图片，MUST NOT 以空白图片静默替代。

#### Scenario: 重新打开
- **WHEN** 用户关闭页面后重新打开编辑器
- **THEN** 自动恢复上次草稿，无需手动导入

#### Scenario: 没有草稿
- **WHEN** 浏览器中不存在草稿
- **THEN** 打开默认空白项目

#### Scenario: 草稿损坏
- **WHEN** 草稿不是合法 JSON 或结构校验失败
- **THEN** 系统提示草稿无法恢复并打开空白项目，原始草稿数据保留供恢复

#### Scenario: 版本不受支持
- **WHEN** 草稿版本高于当前支持版本
- **THEN** 系统提示版本不支持，不加载草稿，原始草稿数据保留供恢复

#### Scenario: 图片资产缺失
- **WHEN** 草稿引用的部分图片资产在浏览器存储中缺失
- **THEN** 系统恢复页面、歌单和其余内容，移除缺失图片并提示丢失数量

#### Scenario: 记住的页面不存在
- **WHEN** 草稿记录的当前页已不存在
- **THEN** 系统恢复到第一页，项目其余内容不变

#### Scenario: 启动恢复期间显示载入提示
- **WHEN** 用户打开编辑器且浏览器中存在可恢复的本地草稿
- **THEN** 画布中央显示带载入动效的「正在载入本地草稿…」提示，且「从左侧导入歌单，再把分类拖到页面上」空态提示不出现

#### Scenario: 恢复完成后移除载入提示
- **WHEN** 本地草稿恢复完成并渲染出项目内容
- **THEN** 载入提示立即从画布消失，恢复的页面、歌单与属性面板可正常操作

#### Scenario: 无草稿时不残留载入提示
- **WHEN** 编辑器启动且浏览器中没有草稿
- **THEN** 载入提示在启动流程结束后消失，只显示默认空白项目和既有画布空态提示

#### Scenario: 恢复失败时回到既有提示
- **WHEN** 草稿损坏、版本不受支持或本地存储不可用
- **THEN** 载入提示消失，系统按既有流程提示失败原因并打开空白项目，画布不残留「正在载入」状态

#### Scenario: 载入状态可被辅助技术感知
- **WHEN** 载入提示显示在画布中央
- **THEN** 其文字通过礼貌播报区域或等效状态语义对辅助技术可见，且不抢走焦点

#### Scenario: 减少动效
- **WHEN** 系统开启减少动效偏好且启动时正在恢复草稿
- **THEN** 载入提示的文字与布局保持可见，载入动效不播放或立即呈现静止状态
